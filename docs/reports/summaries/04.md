# 先把评测口径弄清，再比较模型

本册围绕部署后还能保留多少能力展开：合并与GGUF转换是否改变输出，量化能省多少显存，长上下文和并发是否稳定，以及模型能否在工具任务中正确决策。已执行的准备检查先归入本册，模型实验的结果到齐后再归纳比较。

目前BFCL已冻结13类、3,641条题目，其中AST题2,501条，相关性判断1,140条。29个手写样例实际走过官方handler和检查器，两个准备失败也保留了原始记录。模型尚未在这份清单上生成回复，因此这里没有BFCL模型成绩。

这一阶段先学到的是怎么解释分数：Java/JavaScript整数需要符合该版本检查器的表示方式，损坏的工具调用又可能被当成没有调用。正式评测要把官方类别成绩与解析异常并排看，不能只报一个混合准确率。

## E24：科学问答目前还没测出涨跌

ARC-Challenge 官方 test 已按固定 revision 和 SHA-256 冻结，并经锁定版本的 harness task 核对为 1,172 道题、4,687 条选择题评分请求。零样本模板、评分指标和完整分母已确认。本轮没有加载模型，所以还不能判断工具调用微调有没有影响普通科学问答。首次 HEAD 预检失败及改用固定版本 API、HTTPS GET 和哈希校验的过程都留在实验记录里。
