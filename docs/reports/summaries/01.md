# 这阶段已经确认了什么

独立环境已经能运行 CUDA 和 NF4，模型的监督位置、交叉熵和 LoRA 更新也逐项检查过了。数据已经组成 1k、5k、10k 的嵌套训练集，dev 与 test 各 500 条，任务组没有交集。32 条过拟合已从 9/32 到 31/32，断点也完成加载与续训检查；大规模微调、蒸馏和 Agent 成绩还需要后续实验。

这段准备里，最值得记住的是“能跑”和“正确”之间的差别：驱动看见显卡不等于 Python 能用 GPU，调用能解析不等于参数有可靠来源，loss 下降也不等于新任务做得更好。后面的实验继续围绕这些差别做对照。
