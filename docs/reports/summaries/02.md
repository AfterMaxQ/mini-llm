# 从提示词基线走向正式微调

原模型的完整 dev 比较已经结束：零样本通过 268/500 条轨迹，加入三条训练示例后通过 355/500。少样本提示提高了调用轮表现，也带来了更多本该询问或不调用时的误调用。后续比较使用这一固定提示，同时单独观察调用和不调用两类错误。

正式微调正在按 1k、5k、10k 推进。当前已解决 TRL 重复准备导致 LoRA 冻结的问题，并记录了显存压力下的停止与重新运行。规模效果、最优配置及 test 成绩要等实际训练和生成评测完成后再下结论。
